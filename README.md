<a id="overview"></a>

**Star Defence** is an engaging real-time tower defense game for Windows, developed by steikum. Set in an imaginative 2D universe, players strategically place "white stars" to observe and increase "black stars" while advancing their "Civilization Level." ## ⚡ Key Features
<a id="key-features"></a>

### Core Functionality:
- **Dynamic Unit Placement** — Place "white stars" anywhere on the map to optimize gameplay.
- **Civilization Level Mechanics** — Increase your civilization level by managing resources efficiently.
- **Intuitive Controls** — Use left mouse button for placement, right for cancellation, and WASD for camera movement.
- **Zooming Capability** — Easily zoom in and out with the mouse wheel for better visibility.
